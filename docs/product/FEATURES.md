
# Cumulative Features - v0.7

## Platform
Companies, branches, parties, items, warehouses, audit events, number sequences, fiscal periods and deployment baselines.

## Finance
Chart of accounts, balanced journals, trial balance, AR/AP invoices, receipts/payments, allocations, ageing, bank accounts, income statement and balance sheet foundations.

## Sales
Price lists, quotations, quote conversion, sales orders, credit exposure, delivery, integrated AR invoicing and sales posting.

## Procurement
Purchase requests, RFQs, supplier quotes, comparison, purchase orders, goods receipts, supplier invoice matching and procurement posting.

## Inventory
Immutable movements, balances, reservation, negative-stock policy, weighted-average value, transfers, lot/serial foundation and reorder alerts.

## Integration
Idempotency, document trace, posting profiles, events, exceptions and cross-module transactions.

## Insight
KPIs, financial statements, customer/supplier/warehouse performance, integration health, saved reports, run history, CSV export and data-quality findings.

## Documentation
Role-based guides, implementation playbook, migration guide, UAT/cutover guide, user stories, traceability matrix, FAQ, troubleshooting, glossary and API workflow examples.

## Production and open-source foundation (v0.8)
Users, roles, permissions, authentication, lockout, security events, runtime safety checks, migrations, health probes, Docker production server, TLS proxy, backup/restore, GitHub CI/security/release automation, Apache-2.0 licensing and community governance.
