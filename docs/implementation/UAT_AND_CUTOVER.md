# UAT and Cutover

## UAT coverage

Test each role's daily workflow, boundary validations, exceptions, overrides, reporting, exports and cross-module trace. Include duplicate integration calls, partial delivery/receipt, credit breach, negative stock, match variance and incomplete posting profiles.

## Cutover checklist

Freeze source changes; complete final extract; load in dependency order; reconcile; configure sequences and posting profiles; validate health and reports; obtain sign-off; open access; monitor integration/data-quality findings; retain rollback decision authority.
