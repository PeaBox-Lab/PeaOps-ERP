
# Implementation Consultant Guide

## Phases

1. Discovery: entities, locations, currencies, fiscal calendar, processes, volumes and control requirements.
2. Design: masters, numbering, accounts, statuses, policies, posting profiles and reporting dimensions.
3. Configure: build a clean test company in dependency order.
4. Migrate: cleanse, map, load and reconcile masters/opening data.
5. Validate: unit, integration, security, performance and UAT scenarios.
6. Cut over: freeze, final extract, reconcile, authorize and monitor.
7. Stabilize: triage, adoption, documentation and benefits review.

## Required deliverables

Solution design, data dictionary, mapping workbook, role matrix, control matrix, test evidence, reconciliation pack, cutover plan, rollback plan, support model and signed acceptance.

Use the user stories and traceability matrix as the baseline backlog—not as evidence that every production requirement is complete.
