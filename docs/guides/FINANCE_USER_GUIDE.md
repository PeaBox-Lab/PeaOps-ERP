# Finance User and Controller Guide

## Core workflows

- Create and post balanced journals.
- Create AR/AP invoices and post them to open status.
- Record receipts/supplier payments and allocate them without exceeding outstanding balances.
- Review ageing, trial balance, income statement and balance sheet.
- Configure and review sales/procurement posting profiles with administrators.
- Resolve three-way-match exceptions before AP journal posting.

## Period-end checklist

1. Review unposted/draft documents.
2. Resolve integration exceptions and incomplete profiles.
3. Reconcile AR, AP, inventory value and trial balance.
4. Review statement classification and balance-sheet difference.
5. Export evidence and retain report parameters.

## Key controls

Debits equal credits. Posted journals are immutable in principle. Allocations cannot exceed balances. Supplier match exceptions do not auto-post. Reporting depends on correct account types.
