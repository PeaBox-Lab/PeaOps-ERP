# Inventory and Warehouse User Guide

## Workflow

- Configure item/warehouse tracking and reorder policies.
- Record opening, receipt, issue and adjustment movements.
- Post transfers only between different warehouses.
- Reserve quantities only within available stock.
- Use lot or serial identifiers where policy requires them.
- Review on-hand, reserved, available, average cost and value.

## Controls

Negative stock is blocked unless policy permits it. Serial movements require quantity one. Transfers create equal source and destination quantities. Do not edit ledger history; investigate and use a controlled adjustment.
