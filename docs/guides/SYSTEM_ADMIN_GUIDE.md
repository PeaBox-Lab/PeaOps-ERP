
# System Administrator Guide

## Setup order

1. Company and base currency.
2. Branches and warehouses.
3. Chart of accounts and account types.
4. Fiscal periods.
5. Number sequences for every enabled document type.
6. Customers, suppliers and items.
7. Bank accounts, price lists and inventory policies.
8. Sales and procurement posting profiles.
9. Saved reports and shared views.

## Controls

Keep codes unique within a company. Close or restrict periods through controlled administration when that capability is implemented. Treat posting-account changes as controlled configuration because they affect financial results. Review data-quality findings and incomplete profiles before transaction processing.

## Daily checks

- Health endpoint reports v0.7.0.
- Number sequences exist for enabled flows.
- No unresolved integration events block operations.
- Posting profiles remain complete.
- Reorder and data-quality findings have owners.
