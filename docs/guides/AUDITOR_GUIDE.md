# Auditor and Compliance Reviewer Guide

## Evidence sources

- Journal status and balanced lines.
- Audit events for creation, posting, allocation, overrides and integration actions.
- Integration events with idempotency key and result.
- Document links connecting source and target records.
- Inventory movement ledger.
- Supplier invoice match status and variances.
- Saved report parameters and report-run history.

## Review approach

Trace a sample from source document through operational effects, subledger and journal. Recalculate key totals using exported data. Inspect exceptions, overrides, incomplete posting profiles and accounts without activity. Confirm evidence dates and company scope.

v0.7 does not claim regulatory certification, immutable infrastructure-level audit storage or complete access-control evidence.
