
# Maintainer Release Guide

- Confirm roadmap scope and release version.
- Review user stories, breaking changes and migrations.
- Run cumulative tests, frontend build, migration smoke test and security workflows.
- Verify documentation, license, notice and changelog.
- Generate and inspect the ZIP; exclude secrets and generated caches.
- Tag from reviewed main commit.
- Publish checksums, release notes, known limitations and upgrade/rollback instructions.
- Monitor issues and security reports after release.
