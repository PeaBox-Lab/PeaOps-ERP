|---|---|---|---|
| 0.1 | Foundation | Organization, masters, GL, posting, trial balance, audit, UI shell | Complete |
| 0.2 | Finance | AR, AP, banking, fiscal periods, numbering, ageing | Complete |
| 0.3 | Sales | Pricing, quotations, orders, promises, credit checks, AR handoff | Complete |
| 0.4 | Procurement | Requests, RFQs, supplier quotes, comparison, POs, receipts | Complete |
| 0.5 | Inventory | Stock ledger, balances, transfers, valuation, tracking, reorder | Current |
| 0.6 | Integration | Quote-to-cash and procure-to-pay end-to-end posting | Next |

## Next release: v0.6 Integration

Planned scope: Procurement receipt to inventory, supplier invoice three-way match, Sales delivery to inventory issue, order-to-invoice linkage, controlled subledger-to-GL journals, idempotent document posting and end-to-end Quote-to-Cash / Procure-to-Pay status visibility.
