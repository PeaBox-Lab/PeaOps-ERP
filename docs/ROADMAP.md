# PeaOps Roadmap

| Release | Theme | Major outcomes | Status |
|---|---|---|---|
| 0.1 | Foundation | Organization, masters, GL, posting, trial balance, audit, UI shell | Complete |
| 0.2 | Finance | AR, AP, banking, fiscal periods, numbering, ageing | Complete |
| 0.3 | Sales | Pricing, quotations, orders, promises, credit checks, AR handoff | Complete |
| 0.4 | Procurement | Requests, RFQs, supplier quotes, comparison, POs, receipts | Current |
| 0.5 | Inventory | Stock ledger, transfers, valuation, lots/serials, reorder controls | Next |
| 0.6 | Integration | Quote-to-cash and procure-to-pay end-to-end posting | Planned |
| 0.7 | Insight | Financial statements, dashboards, saved views, exports | Planned |
| 0.8 | Workflow | Approval, delegation, escalation, notifications | Planned |
| 0.9 | Hardening | RBAC, SoD, migrations, import/export, backup/restore, E2E gates | Planned |
| 1.0 | Core GA | Production hardening for Local and Local Server | Planned |

## Next release: v0.5 Inventory

Planned scope: immutable stock ledger, receipts into stock, issues and adjustments, warehouse transfers, on-hand and available quantities, valuation foundations, lots/serials and reorder controls. Procurement receipts will become inventory movements without yet implementing full manufacturing or WMS.
