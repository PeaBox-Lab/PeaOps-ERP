
# Controlled Pilot Operations Guide

## Pilot entry

Complete the production-readiness checklist, use non-critical scope, name business/technical/security owners, validate backup restoration, approve roles, and document accepted residual risks.

## Daily review

Health/readiness, failed logins, locked users, active sessions, integration exceptions, approval queues, data-quality findings, backup age and host/database capacity.

## Change control

Use reviewed tagged releases, verified backups, migration rehearsal and rollback plans. Do not deploy directly from an unreviewed branch.

## Exit criteria

Reconciled business results, acceptable incident rate, successful restore drill, role/SoD review, performance evidence, resolved critical/high defects and approved decision to expand or stop.
