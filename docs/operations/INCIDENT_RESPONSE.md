# Incident Response Runbook

1. Detect and assign incident commander.
2. Classify business, security and data-integrity impact.
3. Contain: restrict access or stop writes without destroying evidence.
4. Preserve request IDs, security events, integration events, logs, database state and release identity.
5. Recover using approved backup/rollback procedures.
6. Validate financial and inventory integrity before reopening.
7. Communicate status through approved channels.
8. Complete root-cause analysis, corrective actions and disclosure where required.
