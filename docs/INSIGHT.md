
# Insight Module - v0.7

Insight is the governed reporting layer over posted Finance and cumulative operational data.

## Financial reporting

Income statement uses revenue/income and debit-nature expense classifications. Balance sheet uses asset, liability and equity classifications and reports any difference. Correct account types are a prerequisite.

## KPIs

The API provides sales, purchases, receivables, payables, inventory value, quote conversion, integration success and approximate receivable/payable days. Zero denominators return zero.

## Operational analytics

Customer sales/outstanding, supplier order commitments, warehouse inventory and integration health are grouped within company scope.

## Saved reports and exports

Users can store report type, JSON parameters, owner and shared status. Report runs store generation context. Trial balance CSV export applies escaping rules.

## Data quality

Findings identify accounts without activity, incomplete posting profiles and integration exceptions. Findings are decision-support signals and require accountable review.
