
# Frequently Asked Questions

## Is v0.7 production ready?
No. It is a cumulative engineering release with explicit documented hardening gaps.

## Does PeaOps support Local, Server and Cloud?
The architecture supports these paths, but desktop packaging and Cloud GA controls are future milestones.

## Can posted transactions be edited?
The product principle is immutability; correction should use controlled reversal or adjustment workflows.

## What happens when a posting profile is missing?
Operational documents can be created, but automatic GL posting is skipped and data-quality reporting flags incomplete configuration.

## Are dashboard numbers live?
The current frontend is a designed operator shell with illustrative values. Use APIs against the configured database for actual results.
